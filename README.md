# npn

VPN-сервис для пользователей из России с обходом блокировок.

- **Протоколы:** Xray VLESS + Reality и Hysteria2. Подписка содержит оба, и если один режут, клиент переключается на другой.
- **Панель:** [3x-ui](https://github.com/MHSanaei/3x-ui) v3 управляет пользователями, сроками, трафиком и выдаёт ссылки-подписки.
- **Продажи:** Telegram-бот из этого репозитория. Пробный период, оплата Telegram Stars, выдача и продление подписки.
- **Клиенты:** готовые приложения (Happ, Hiddify, Streisand), своё писать не нужно.

## Архитектура

```
Пользователь ──Telegram──▶ бот ──API (Bearer-токен)──▶ 3x-ui
     │                                                   │
     ├──── подписка https://IP:2096/sub/<subId> ◀────────┤
     └──── VLESS Reality :443 / Hysteria2 :8443 ──▶ xray ┘
```

## Структура

- `bot/` — Telegram-бот (aiogram 3, SQLite)
- `servych/` — сайт «Сервыч»: свой VPN-сервер для семьи (FastAPI)
- `deploy/README.md` — как подключить бота к 3x-ui
- `tests/` — тесты

## Запуск

Подробно в [deploy/README.md](deploy/README.md). Коротко:

```bash
cp .env.example .env   # заполнить токен бота и доступ к 3x-ui
docker compose up -d --build
```

Тесты:

```bash
pip install -r requirements-dev.txt
pytest
```

## Сайт «Сервыч»

Сайт для продукта «свой сервер для семьи». Запускается вместе с ботом (сервис `web` в docker-compose) на порту `SERVYCH_PORT`, по умолчанию 8088.

- **Вход** через Telegram, без пароля: сайт даёт ссылку `t.me/<бот>?start=login_<код>`, бот подтверждает код.
- **Кабинет клиента:** статус сервера, срок оплаты, список людей с трафиком. Человека добавляют одной кнопкой, ему уходит приглашение `/c/<токен>` с тремя шагами для iPhone, Android и компьютера и кнопкой «Добавить в Happ». Есть кнопка «Не работает, сменить адрес».
- **Админка** `/admin` (для `ADMIN_IDS`): заявки на новые серверы и смену IP, платежи, доступ к 3x-ui каждого клиента. Когда админ запускает сервер или меняет его адрес, клиенту приходит сообщение в Telegram.
- **Оплата:** CryptoBot (нужен `CRYPTOBOT_TOKEN`) и «через поддержку», которую админ отмечает вручную. Для СБП оставлено место в `servych/payments.py`.
- **Подписка через сайт:** если `SERVYCH_PUBLIC_URL` начинается с `https://`, ссылка в приложении ведёт на сайт (`/s/<токен>`), а сайт берёт её с сервера клиента. Тогда после смены IP приложения сами получают новый адрес.

Сервер каждого клиента пока поднимается вручную: 3x-ui с API-токеном, его адрес вписывается в админке.

Настройки в `.env`: `SERVYCH_PORT`, `SERVYCH_PUBLIC_URL`, `SERVYCH_PRICE_RUB`, `CRYPTOBOT_TOKEN`, `SERVYCH_SECURE_COOKIES` (включить после HTTPS).
