# npn

VPN-сервис для пользователей из России с обходом блокировок.

- **Протокол:** Xray, VLESS + Reality. Трафик выглядит как обычный HTTPS к крупному сайту, поэтому его трудно отличить и заблокировать.
- **Панель:** [Marzban](https://github.com/Gozargah/Marzban) управляет пользователями, сроками, трафиком и выдаёт ссылки-подписки.
- **Продажи:** Telegram-бот из этого репозитория. Пробный период, оплата Telegram Stars, выдача и продление подписки.
- **Клиенты:** готовые приложения (Hiddify, v2rayNG, Streisand, V2Box), своё писать не нужно.

## Архитектура

```
Пользователь ──Telegram──▶ бот ──API──▶ Marzban (главный сервер)
     │                                      │
     └──── VLESS+Reality :443 ────▶ ноды Xray (NL, FI, ...)
```

## Структура

- `bot/` — Telegram-бот (aiogram 3, SQLite)
- `deploy/xray_config.json` — шаблон конфига Xray с Reality
- `tests/` — тесты

## Запуск

Подробно в [deploy/README.md](deploy/README.md). Коротко:

```bash
cp .env.example .env   # заполнить токен бота и доступ к Marzban
docker compose up -d --build
```

Тесты:

```bash
pip install -r requirements-dev.txt
pytest
```
